# Trying Peko: your tasks

Thanks for helping. **We're testing Peko, not you.** If something is
confusing or breaks, that's exactly what we want to find.

**Peko** lets you run your own AI assistant, called a **peko**, on this
computer. You'll set one up and use it, by following Peko's own guides:

- **Getting Started:** https://github.com/ConekoAI/peko-runtime/blob/master/docs/getting-started/GETTING_STARTED.md
- **Tutorial:** https://github.com/ConekoAI/peko-runtime/blob/master/docs/getting-started/TUTORIAL_FIRST_PEKO.md

**As you go:**
- **Think aloud.** Say what you're looking for, what you expect, and what
  surprises you.
- **Use only the guides and this page.** You can copy commands from the
  guides and paste them into the terminal.
- **If you're stuck:** say so, try the guide's *Troubleshooting* section,
  and if you're still stuck after a couple of minutes, ask the observer.
- **Your model card** has four values you'll need in task 2. Treat the key
  like a password.

---

### 1. Install Peko
Follow *Getting Started → 1. Install*. Peko has only test releases so far,
so add `--version 0.1.0-rc.4` as the guide's note explains.
**Done when** `peko --version` prints a version.

### 2. Connect your model
Follow *2. Add a model*, using the values on your model card, then check that
it works.
**Done when** the check says *Connection successful*.

### 3. Create your peko
Follow *3. Start the daemon* and *4. Create your peko*. Pick any name you
like for your peko.
**Done when** Peko says your peko *is alive*.

### 4. Talk to it
Ask your peko three different things you'd really ask an assistant. Then
read the conversation back (*5. Talk to it*).
**Done when** you've had three answers and can see them in the conversation.

### 5. Have it remember something
Tell it your first name and one thing you like. Then, **in a new message**,
ask what it knows about you (*Tutorial → 2*).
**Done when** it tells you what you told it.

### 6. Set a reminder
Ask it to remind you about something **in 3 minutes**, then wait for the
reminder (*Tutorial → 3*).
**Done when** the reminder shows up in your conversation.

### 7. Teach it a skill
Follow *Tutorial → 4* to add a skill, then use it.
**Done when** its answer follows the skill.

### 8. (If there's time) Back it up
Follow the first part of *Tutorial → 5*, to export your peko.
**Done when** a `.peko` file appears.

---

**Afterwards**, the observer will ask you a few questions. There are no wrong
answers.
